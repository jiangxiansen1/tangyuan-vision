## 九个板块，各管一件事

打开后台，左侧是这九个入口。你日常只会用到前四个。

| 板块 | 管什么 | 多久用一次 |
|---|---|---|
| **摄影作品** | 加照片、改标题 | 每次拍了新照片 |
| **地球与旅行** | 去过哪里、有哪些城市 | 去了新地方 |
| **个人品牌** | 首页第一屏的文字、个人宣言 | 想改文案时 |
| **联系方式** | 抖音、邮箱、GitHub | 换账号时 |
| 个人项目 | 项目卡片 | 做了新项目 |
| 随笔与思考 | 文字文章 | 想写时 |
| AI 与编程 | 实验室笔记 | 偶尔 |
| 摩旅与骑行 | 骑行路线 | 偶尔 |
| 网站设置 | 背景图等全局项 | 基本不动 |

## 最常做的三件事

### 1. 加一张照片

**摄影作品** → 作品列表 → 右上角「添加」→ 填这几项就够：

| 字段 | 填什么 | 必须吗 |
|---|---|---|
| 唯一标识 | 英文小写加连字符，如 `2025-11-13-dali-01` | ✅ 必须，定了别改 |
| 标题 | 照片名字 | ✅ |
| 分类 | 风光 / 人像 | ✅ |
| 原图 | 点上传，选文件 | ✅ |
| 原图宽度 / 高度 | 像素数，如 1920 / 1280 | ✅ 决定页面不留白 |
| 一句话描述、拍摄时间、地点、相机 | 想填就填 | 可选 |
| 缩略图 | 留空会自动用原图 | 可选 |

**其余字段不认识就保持默认**，「内容来源」选「真实拍摄」。

⚠️ 照片请用**原图**。微信/QQ 传过的图会丢掉拍摄位置，地球上的照片点就没有了。

### 2. 加一个去过的地方

**地球与旅行** → 选国家 → 「到访城市」里加城市名和省份。

这里填的城市会显示在右侧详情面板，也会让对应省份在地球上整片加深。

### 3. 改首页那句话

**个人品牌** → 找到「个人宣言」→ 改 → 保存。

这是首页那句「你这一生太安静 该出发了」的来源。

## 几个按钮

- **保存**（右上角）：写进草稿，还没发布
- **发布**（Publish）：真正提交，2 分钟后上线
- **预览**：看大致效果，但排版不一定和真站一样
- **媒体**：所有上传过的图片，别在这里删正在用的图为妙

---

## 看不到你刚改的内容？

1. **等 2 分钟** —— 每次保存都会触发一次构建
2. **强制刷新** —— `Ctrl + Shift + R`（普通刷新会用到缓存的旧页面）
3. 还是不行 → 去 https://github.com/jiangxiansen1/tangyuan-vision/actions 看最近一次构建是不是绿的

---

## 不要做的事

- ❌ 别改「唯一标识」—— 旅行记录靠它引用照片，改了会断
- ❌ 别填你不想公开的信息 —— 这个后台写的内容**全部会公开到网站上**
- ❌ 别删「媒体」里不认识的文件 —— 可能正被某条记录用着
- ❌ 别用「示例图像」标记你自己拍的照片
