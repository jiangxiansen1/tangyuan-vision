## 2. 地球 — 省级边界、内部点击与两级导航（本轮新增）

脚本 `tools/verify-province.cjs`，结果 `tools/_verify/province/report.json`。

| 用例 | 结果 |
|---|---|
| 太平洋点击不虚构省份、不开面板 | **通过**（country=null, province=null, 无 `.rpanel`） |
| 先选中国 → 面板显示「中国」 | **通过** |
| 点击 四川 / 新疆 / 西藏 / 内蒙古 / 甘肃 内部 → 省级面板 | **通过**（5/5，面包屑 = 省名） |
| 同国切换省份（四川 → 甘肃）面板更新 | **通过** |
| 面包屑点「中国」返回国家级面板 | **通过** |
| 直辖市几何：上海 / 北京（经 resolve 路径） | **通过**（上海市 / 北京市） |
| 城市优先级：点击北京城市标记 → 城市卡片「北京」 | **通过**（城市优先于省级） |
| 切换到另一国（埃及 818）→ 面板「埃及」、无旧省份面包屑 | **通过** |
| 桌面 / 手机视口无溢出、0 控制台错误 | **通过** |

> 已知取舍：省级数据加载后，落在中国境内的点击会命中某个省（这是要求的两级导航行为）；
> 返回国家级用面包屑或关闭按钮。北京/上海等直辖市面积很小，当镜头拉近、城市标记可见时，
> 点中城市会打开城市卡片（**城市优先级**，符合要求）。
