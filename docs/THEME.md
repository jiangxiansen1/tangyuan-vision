# 浅色主题与视觉系统（V3）

V3 从暗色基底改为**浅色优先**。这不是把背景从黑改成白——布局、字体层级、材质、
留白与图片比例都重构了。本文说明主题系统怎么工作，以及改的时候要注意什么。

---

## 1. 两层基座，一个语义层

```
:root                       ← 浅色（默认，公开页面）
[data-ground="dark"]        ← 深色（仅两个地方）
```

**为什么保留深色**：只有两处真的需要。
- **地球页**——受光的球体只能在不受光的场里读出来，城市灯光在白底上没有意义。
- **摄影灯箱**——明亮的周围环境会改变你对图片的感知。

这两个地方是**刻意的例外**，不是没改完。

### 语义层

组件**只引用** `--color-*` / `--glass-*` / `--sh-*`，**从不引用色阶原值**
（`--c-ink`、`--c-frost` 之类）。这条规则的意义是：换主题是改一个文件，
不是改几十个组件。

---

## 2. 一个必须知道的例外：`--c-mist`

`--c-mist` 是**自适应**的——它同时是色阶名和语义令牌。这是刻意的，理由如下：

它被用作 `color-mix(in srgb, var(--c-mist) N%, transparent)` 共 **68 处**，
语义是"在当前底色上叠一层很淡的覆盖"（hover 填充、细线、骨架屏、装饰纹理）。
在深色主题下这层必须是白的，在浅色主题下必须是墨色。

按颜色命名它确实让人困惑，但为了这个改名要动 68 个调用点，
而那些文件本身没有别的改动。所以选择在这里写清楚，而不是制造一个大 diff。

```css
/* 浅色（默认） */
--c-mist: var(--c-ink);

/* 深色 */
[data-ground='dark'] { --c-mist: #ffffff; }
```

**它不用作涂色**——想当颜色用之前先确认。

## 3. 玻璃材质在两种底色上的区别

液态玻璃是**一套材质三个层级**，不是三种外观。六个层：

| 层 | 作用 |
|---|---|
| L1 | `backdrop-filter` 模糊 + 饱和 + 可选 SVG 折射 |
| L2 | 本体着色（垂直渐变，从不是平涂） |
| L3 | 内描边（上沿高光、下沿压暗） |
| L4 | 轮廓光 |
| L5 | 指针跟踪高光 |
| L6 | 色散（上下曲率处的青/暖色边） |

**浅色不是"同一块玻璃调亮一点"。** 在深色上玻璃靠"比周围亮"读出来；
在浅色上这个关系反了：玻璃靠**边缘更暗、中间更亮**读出来。所以层的作用变了：

- L2 的着色变成极淡的冷灰，而不是深蓝
- L3 的亮边翻到**下沿**，因为光在上方，玻璃的上沿背光
- L5 的高光降到极低 alpha——白底上的白色高光看不见，
  真正起作用的是**边缘**而不是填充
- L4 多了一层很宽的柔和阴影，这是把白色玻璃从白色页面上分开的东西

两者都通过同一组变量表达，所以组件不知道自己在哪种底色上。

## 4. 场景

`[data-scene="..."]` 只能改**色相和环境光**，**不能改可读性**——
文本类变量从不在场景级重设，所以对比度只验证一次，全局有效。

| 场景 | 底色 | 说明 |
|---|---|---|
| `home` | 浅 | 最亮，留白最多 |
| `photography` | 浅 | 暖色偏钨丝灯 |
| `earth` | **深** | 宇宙背景，唯一允许纯黑的场景 |
| `riding` | 浅 | 钠灯橙 |
| `lab` | 浅 | 测量薄荷绿 |
| `projects` | 浅 | 蓝图蓝 |
| `journal` | 浅 | 最安静 |
| `contact` | 浅 | 冰川蓝 |
| `secret` | **深** | 同一栋楼在夜里，不是第二套主题 |

## 5. 对比度

针对 `--color-canvas` (#F4F6F8) 实测：

| 变量 | 色值 | 对比度 |
|---|---|---|
| `--color-text` | `#161B22` | **15.8:1** |
| `--color-text-muted` | `#5C6672` | **5.4:1** |

两者都通过 WCAG AA。深的底色下的数值见 `tokens.css` 中的 `--contrast-body`。

**注意**：核心窗口的文字落在深色图片遮罩上，那里用的是浅色文字（`--c-frost`），
这是刻意的——遮罩本身是深的，写在上面的字必须浅。

## 6. 无障碍覆盖

三种状态覆盖玻璃材质：

```css
[data-contrast='high']        /* 强制高对比：不透明表面，去掉折射与高光 */
[data-transparency='reduced'] /* 减少透明：去掉 backdrop-filter，用不透明替代 */
@media (hover: none)          /* 触摸设备：没有指针跟踪，去掉高光层 */
@media (max-width: 767px)     /* 手机：关掉折射，太贵且局促 */
prefers-reduced-motion        /* 动画降级，见 motion.css */
```

这些都能在应用内设置里切换（右下角 ⚙），不是装饰。

---

## 7. 改主题时要注意的坑

1. **不要用 `--c-mist` 当涂色。** 它是覆盖层。
2. **不要在场景级重设文本变量。** 那会绕过全局对比度验证。
3. **深色场景要成对声明。** 只设 `--color-canvas` 会让玻璃渲染出
   浅色玻璃压在深色底上，看起来像坏了。
4. **改 `tokens.css` 里的色阶值，不要改语义层映射** —— 除非你确实要
   改变两种底色下的关系。
5. **不要用 PowerShell 的 `Get-Content -Raw` → `Set-Content` 改这些文件。**
   Windows PowerShell 5.1 会按 CP936 读、按 UTF-8 写，
   把破折号变乱码、破坏中文、加 BOM。用编辑器或 `node fs`。
   （这个坑在 V3 期间真实踩过一次，`index.html` 被毁过。）
